# Trivial 2.0 - Rules

## How to Play

Welcome to Trivial 2.0! Here are the rules:

1. **Add Players:** Start by adding player names on the start screen.
2. **Choose a Specialisation:** Each player can select a specialisation to get extra boxes in specific categories.
3. **Ask Questions:** Select a category (or Random) and click "Mostrar pregunta" to display a trivia question.
4. **Mark Correct Answers:** Click the corresponding box when a player answers correctly.
5. **Use the Timer:** Set a timer duration and click "Iniciar temporizador" to start the countdown.
6. **Win the Game:** The first player to fill all their boxes wins! Click "Mostrar ganador" to declare the winner.

## Categories

Check the legend in the game screen to see category colors and their meanings.

## Tips

- Use the "Random" category option for variety.
- The timer helps keep the pace of the game.
- Specialisations add extra challenges for experienced players.
